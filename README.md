# Visual Deformation for Pseudo-Haptic Softness Perception in AR

## Project Overview
This project investigates whether **visual manipulation alone** can induce a convincing pseudo-haptic perception of softness during bare-handed interaction in mid-air AR, without physical objects or active tactile actuators.

Users interact with a **virtual soft ball** using a natural semi-squeeze gesture (palm and thumb). By manipulating the Control/Display (C/D) ratio of the visual deformation of the object, the visual feedback associated with the user's physical hand movement is altered across three gain levels: **low (0.6)**, **medium (1.0)**, and **high (1.4)**.

The study was conducted using a **Magic Leap 2** headset with native OpenXR hand tracking and a custom Unity AR prototype.


### Research Question
> Can visual manipulation alone induce a convincing pseudo-haptic perception of softness during bare-handed interaction in mid-air AR?

## Experiment Design

- **Headset:** Magic Leap 2 (native OpenXR hand tracking, environment dimmed to maximum)
- **Development environment:** Unity 2022
- **Participants:** 13 (aged 22–28; 11 right-handed, 2 left-handed)
- **Trials:** 6 per participant (2 repetitions × 3 gain levels), fixed sequence: medium → low → high → low → high → medium
- **Trial rating:** "How clearly did you perceive the deformation of the ball?" (1–7 Likert scale)
- **Post-experiment questionnaire:** 7 Likert-scale questions (Q1–Q7) on softness, elasticity, contact believability, thumb contribution, visual touch influence, object-like perception, and movement match; plus Q8 (Yes/No) on perceived visual-motor disconnection with timing follow-up

---

## Statistical Analysis

The main analysis was performed in Python (`notebooks/`) and validated in JASP (`analysis/`).

- **Friedman test** (non-parametric repeated-measures): *χ²*(2) = 11.91, *p* = .003, Kendall's *W* = 0.458
- **Post-hoc Wilcoxon signed-rank tests** with Bonferroni correction (Python)
- **Post-hoc Conover test** with Holm correction (JASP)
- Both methods confirmed: high gain differed significantly from low and medium; low vs. medium was not significant

Key finding: **visual deformation gain significantly influences perceived softness**, with the high-gain condition producing the strongest perceptual effect.

### Key Results

| Comparison     | Significant |
|----------------|--------------------------|
| low vs medium  | No    |
| medium vs high | Yes   |
| low vs high    | Yes    |

- The **high gain level** produced the clearest perceived deformation.
- 9 out of 13 participants reported visual-motor disconnection (Q8)
- 66.7% of disconnections occurred when the **thumb was added**, identifying it as the most critical moment for the illusion
- Thumb contribution (Q4) received the lowest post-questionnaire score (*M* = 3.77, *SD* = 2.05)

## Reproducing the Analysis

### Requirements

1. Install Unity 2022 LTS (https://unity.com/releases/editor/archive)
2. Install the Magic Leap Hub (https://ml2-developer.magicleap.com/downloads)
3. Install the Magic Leap 2 SDK packages via ML Hub

For  additional information follow the [OpenXR Unity getting started guide](https://developer-docs.magicleap.cloud/docs/guides/unity-openxr/getting-started/openxr-unity-getting-started/).

### Unity Prototype

The AR prototype is located in `pseudoHapticsFeedback/`. The prototype is provided for reference and is not required to reproduce the statistical analysis.

New data can be collected by opening the Unity prototype through Unity Hub and running the experiment on Magic Leap 2. The new CSV files will be exported with the `CogAr_test` naming convention. To change the `participant_id`, use the Inspector in the Unity project before running a new test session.

### Analysis

1. Place the raw CSV files (one per participant) in `data/raw/`
2. Open `notebooks/experimental_analysis.ipynb`
3. Run all cells in order — the notebook will:
   - load and merge all CSV files from `data/raw/`
   - split data into pre-, trial-, and post-experiment phases
   - generate all plots saved to `plots/`
   - run the Friedman test and post-hoc Wilcoxon comparisons
   - export the aggregated dataset to `data/processed/participant_gain_means_for_jasp.csv`
4. Open `data/processed/participant_gain_means_for_jasp.csv` in JASP to replicate the Friedman test and Conover post-hoc comparisons.
